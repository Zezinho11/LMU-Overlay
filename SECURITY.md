# Security policy

## Reporting

Do not publish suspected vulnerabilities, exploitable crashes, credential leaks,
or anti-cheat bypass findings in a public issue. Contact the maintainers privately
through GitHub Security Advisories once the repository is published.

## Supported versions

Only the latest published release is supported during pre-1.0 development.

## Non-goals

This project will not implement, document, or accept mechanisms intended to evade,
disable, bypass, or tamper with Easy Anti-Cheat or Le Mans Ultimate protections.
