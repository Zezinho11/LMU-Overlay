# ADR 0001: .NET 10 baseline

- Status: accepted
- Date: 2026-07-28

## Decision

Use C# and .NET 10 for the core, adapters, tooling, and initial Windows hosts.

## Rationale

The runtime provides memory-mapped files, modern immutable models, mature testing,
NativeAOT options, and direct Windows/SteamVR interop while keeping most business
logic portable and testable.

## Consequences

Windows-native rendering and SteamVR calls stay behind interfaces. The project
tracks the active .NET 10 servicing line and pins the SDK through `global.json`.
